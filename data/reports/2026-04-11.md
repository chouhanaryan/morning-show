# Weekly Briefing — April 11, 2026

## Top Stories

**Anthropic's Claude Mythos Discovers Thousands of Zero-Days in Major Systems**  
Anthropic launched Project Glasswing, a cybersecurity initiative using its Claude Mythos model to identify vulnerabilities at scale. The AI system has reportedly found thousands of zero-day flaws across major systems, with partner organizations including Amazon Web Services, Apple, Broadcom, Cisco, and CrowdStrike. This represents a significant milestone in AI-assisted security research, though the full implications for vulnerability disclosure and remediation timelines remain to be seen. [The Hacker News]

**France Announces Migration from Windows to Linux Citing Strategic Risk**  
The French government is switching from Windows to Linux across its systems, explicitly citing reliance on U.S. technology as a strategic risk. Multiple sources confirmed the decision, which represents one of the largest government migrations to open-source infrastructure in recent years. The move aligns with broader European digital sovereignty initiatives and could influence other nations' technology procurement strategies. [TechCrunch, XDA Developers via Hacker News]

**North Korea's Six-Month Social Engineering Operation Nets $285M from Drift Exchange**  
A DPRK-linked operation culminating on April 1 stole $285 million from Drift, a Solana-based decentralized exchange, following a six-month targeted social engineering campaign that began in fall 2025. Separately, North Korean actors published 1,700 malicious packages across npm, PyPI, Go, Rust, and PHP ecosystems as part of the ongoing "Contagious Interview" campaign, impersonating legitimate developer tooling. These incidents underscore the sophistication and persistence of DPRK supply chain attacks targeting both cryptocurrency platforms and software development infrastructure. [The Hacker News]

**Multiple Critical Zero-Days Under Active Exploitation**  
Several critical vulnerabilities are being actively exploited in the wild this week. Fortinet patched CVE-2026-35616 (CVSS 9.1) in FortiClient EMS, a pre-authentication API access bypass flaw. Adobe Reader has been exploited via malicious PDFs since December 2025, with the first artifacts appearing on VirusTotal in November. Most concerning, Flowise AI platform's CVE-2025-59528 (CVSS 10.0) enables remote code execution and has over 12,000 exposed instances, while Marimo's CVE-2026-39987 (CVSS 9.3) was exploited within 10 hours of public disclosure. [The Hacker News]

**Supply Chain Attacks Target Developer Tools and Browser Extensions**  
Multiple supply chain compromises emerged this week: CPU-Z and HWMonitor were compromised in a supply chain attack [The Register via Hacker News]; Smart Slider 3 Pro plugin (800,000+ installations) distributed a backdoored version via compromised Nextend servers [The Hacker News]; 36 malicious npm packages disguised as Strapi CMS plugins deployed reverse shells and persistent implants [The Hacker News]; and a JSON formatter Chrome plugin now injects adware [GitHub via Hacker News]. The GlassWorm campaign evolved to use a new Zig dropper infecting multiple developer IDEs through a malicious Open VSX extension impersonating WakaTime. [The Hacker News]
