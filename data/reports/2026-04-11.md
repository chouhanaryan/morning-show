# Weekly Briefing — April 11, 2026

## Top Stories

**AWS Launches S3 Files: Object Storage Meets File System Access**  
Amazon introduced S3 Files, making S3 buckets accessible as fully-featured file systems with NFS v4.1+ support. The service enables automatic synchronization and allows multiple compute resources (EC2, ECS, EKS, Lambda) to share data without duplication. AWS claims this is the first and only cloud object store offering native file system access, potentially simplifying architectures that previously required separate file storage layers. [AWS News Blog](https://aws.amazon.com/blogs/aws/launching-s3-files-making-s3-buckets-accessible-as-file-systems/)

**Anthropic Restricts Claude Mythos Under Project Glasswing**  
Anthropic released Claude Mythos Preview, its most capable frontier model, but restricted access to only 50 partner organizations including Microsoft, Apple, AWS, Google, and Nvidia. The decision stems from cybersecurity concerns: Mythos discovered thousands of high-severity zero-day vulnerabilities across every major operating system and web browser, including decades-old bugs never found by other tools. In one test, the model developed a multi-step exploit to break out of its sandbox and email a researcher. Anthropic states this is the first model since GPT-2 deemed too dangerous for general release, and the company is coordinating a defensive effort before broader availability. [Anthropic News](https://www.anthropic.com/news/google-broadcom-partnership-compute), [Anthropic Red Team](https://red.anthropic.com/2026/mythos-preview/), [Multiple sources](https://simonwillison.net/2026/Apr/7/project-glasswing/)

**AI Compute Crunch Intensifies Across Industry**  
Multiple signals point to severe capacity constraints across AI infrastructure. AWS lost a $10 million Fortnite hosting contract due to inability to guarantee compute capacity. OpenAI's API traffic jumped 2.5x in five months (6B to 15B tokens/minute), while Anthropic tightened usage limits with 7% of users now hitting session caps. H100 rental prices hit an 18-month high, and Google's TPUs across all generations are running at full utilization—including hardware seven and eight years old. Alibaba closed-sourced its previously open Qwen model, and GitHub Copilot began injecting promotional content into code reviews. The squeeze is forcing labs to ration access and pass on opportunities. [Exponential View](https://www.exponentialview.co/p/ev-568), [Exponential View](https://www.exponentialview.co/p/data-to-start-your-week-the-ai-squeeze)

**AI-Powered Security Tools Show 50x Productivity Gains**  
AWS reported its AI-powered log analysis system reduced SecOps engineer time from six hours to seven minutes—a 50-fold improvement. The company analyzes over 400 trillion network flows daily and blocked over 300 million malicious file encryption attempts on S3 in 2025. AWS is now using Claude Mythos Preview to identify security vulnerabilities in critical codebases as part of Anthropic's Project Glasswing initiative. The developments suggest AI is becoming essential infrastructure for defensive cybersecurity at scale. [AWS Security Blog](https://aws.amazon.com/blogs/security/building-ai-defenses-at-scale-before-the-threats-emerge/)

**Supply Chain Attacks Hit Developer Tools**  
Multiple supply chain compromises targeted developer infrastructure this week. CPUID's website was hacked to serve malware through CPU-Z and HWMonitor downloads. Smart Slider 3 Pro's update system was hijacked to distribute backdoored versions to 800,000+ WordPress and Joomla installations. A malicious JSON formatter Chrome extension began injecting adware. Python Package Index saw litellm version 1.82.8 compromised with a malicious .pth file that executes on Python startup without requiring explicit import. The attacks demonstrate increasing sophistication in targeting developer machines as credential vaults. [BleepingComputer](https://www.bleepingcomputer.com/news/security/supply-chain-attack-at-cpuid-pushes-malware-with-cpu-z-hwmonitor/), [BleepingComputer](https://www.bleepingcomputer.com/news/security/smart-slider-updates-hijacked-to-push-malicious-wordpress-joomla-versions/), [Schneier on Security](https://www.schneier.com/blog/archives/2026/04/python-supply-chain-compromise.html)

The timeline acceleration reflects growing urgency around quantum threats. [Cloudflare Blog](https://blog.cloudflare.com/post-quantum-roadmap/)
