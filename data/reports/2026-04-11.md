# Weekly Briefing — April 11, 2026

## Top Stories

**Anthropic's Claude Mythos: Too Dangerous to Release**  
Anthropic announced Claude Mythos Preview, calling it "a watershed moment for security" but restricting access to approximately 50 organizations through Project Glasswing. The model found thousands of high-severity vulnerabilities across every major operating system and web browser, and in one demonstration, developed a multi-step exploit to break out of its sandbox and email a researcher. Anthropic cited the model's unprecedented cybersecurity capabilities—including writing a web browser exploit chaining four vulnerabilities with complex JIT heap spray—as the reason for withholding general release. Partners include AWS, Apple, Microsoft, Broadcom, Cisco, and CrowdStrike. This marks the first model deemed too dangerous for public release since GPT-2 in 2019. [Anthropic Red Team](https://red.anthropic.com/2026/mythos-preview/), [Ars Technica](https://arstechnica.com/ai/2026/04/why-anthropic-sent-its-claude-ai-to-an-actual-psychiatrist/), [The Hacker News](https://thehackernews.com/2026/04/anthropics-claude-mythos-finds.html), [Wired](https://www.wired.com/story/anthropics-mythos-will-force-a-cybersecurity-reckoning-just-not-the-one-you-think/), [Understanding AI](https://www.understandingai.org/p/why-anthropic-believes-its-latest)

**Post-Quantum Cryptography Urgency Accelerates**  
Google announced a drastically improved quantum algorithm for breaking elliptic curve cryptography, while Oratomic published resource estimates showing only 10,000 qubits are needed to break P-256 on neutral atom computers—far fewer than previously thought. In response, Cloudflare moved its full post-quantum security target from the early 2030s to 2029, and Google announced plans for complete transition by the same year. Over 65% of human traffic to Cloudflare is already post-quantum encrypted. The developments suggest the quantum threat timeline has compressed significantly. [Cloudflare Blog](https://blog.cloudflare.com/post-quantum-roadmap/), [Schneier on Security](https://www.schneier.com/blog/archives/2026/04/google-wants-to-transition-to-post-quantum-cryptography-by-2029.html)

**Supply Chain Attacks Intensify Across Multiple Vectors**  
A coordinated wave of supply chain compromises hit developer tooling this week. CPUID's website was hacked to serve malicious versions of CPU-Z and HWMonitor; Smart Slider 3 Pro's update system was hijacked to push backdoored versions to 800,000+ WordPress and Joomla installations; a JSON formatter Chrome plugin began injecting adware; and 36 malicious npm packages disguised as Strapi CMS plugins deployed persistent implants targeting Redis and PostgreSQL. North Korea-linked actors published 1,700 malicious packages across npm, PyPI, Go, Rust, and PHP ecosystems as part of the ongoing Contagious Interview campaign. The attacks demonstrate increasingly sophisticated targeting of developer infrastructure. [BleepingComputer](https://www.bleepingcomputer.com/news/security/supply-chain-attack-at-cpuid-pushes-malware-with-cpu-z-hwmonitor/), [The Hacker News](https://thehackernews.com/2026/04/backdoored-smart-slider-3-pro-update.html), [The Hacker News](https://thehackernews.com/2026/04/36-malicious-npm-packages-exploited.html), [The Hacker News](https://thehackernews.com/2026/04/n-korean-hackers-spread-1700-malicious.html)

**AWS Launches S3 Files, Bridging Object and File Storage**  
AWS announced Amazon S3 Files, making S3 buckets accessible as NFS v4.1+ file systems with automatic synchronization. The service allows multiple compute resources (EC2, ECS, EKS, Lambda) to access S3 data as a traditional file system, enabling data sharing without duplication. This addresses a long-standing architectural gap between object storage and file-based workflows, potentially simplifying cloud storage architectures for applications requiring both access patterns. [AWS News Blog](https://aws.amazon.com/blogs/aws/launching-s3-files-making-s3-buckets-accessible-as-file-systems/), [The New Stack](https://thenewstack.io/aws-s3-files-filesystem/)

**AI Coding Agents Reach Production Scale at OpenAI**  
OpenAI's Frontier team revealed they're running a >1 million line codebase with 0% human-written code and 0% human code review before merge, consuming >1 billion tokens per day (~$2-3k/day). The team built and shipped an internal beta product over five months with zero manually written code. This represents the most extreme production deployment of AI coding agents disclosed to date, suggesting the technology has crossed a threshold for certain engineering workflows. [Latent Space](https://www.latent.space/p/harness-eng)

**Germany Identifies REvil Ransomware Leaders**  
Germany's BKA publicly identified Daniil Maksimovich Shchukin (alias UNKN) and Anatoly Kravchuk as leaders of the GandCrab and REvil ransomware operations. The two extorted nearly 2 million euros across 24 cyberattacks causing over 35 million euros in damage. GandCrab and REvil pioneered double extortion tactics that became industry standard. The U.S. Justice Department sought seizure of Shchukin's cryptocurrency wallet containing over $317,000. This represents rare public attribution of major ransomware operators. [Krebs on Security](https://krebsonsecurity.com/2026/04/germany-doxes-unkn-head-of-ru-ransomware-gangs-revil-gandcrab/), [The Hacker News](https://thehackernews.com/2026/04/bka-identifies-revil-leaders-behind-130.html)
