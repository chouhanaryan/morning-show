**Claude Mythos: Restricted Deployment, Government Use, and the Cybersecurity Threshold**

- Mythos is restricted to ~50 organizations under Project Glasswing (including Microsoft, Apple, AWS, CrowdStrike) and discovered thousands of vulnerabilities across major OSes, including a 27-year-old OpenBSD bug and 16-year-old FFmpeg flaw — and weaponized Firefox vulnerabilities into 181 usable attacks vs. two from the prior flagship model.
- The NSA is using Mythos despite it appearing on a blacklist; Anthropic briefed the Trump administration on its capabilities amid an ongoing legal dispute with the DoD; OpenAI is mirroring the approach with GPT-5.4-Cyber distributed to hundreds of vetted organizations.
- The UK's AI Safety Institute independently confirmed Anthropic's claims about Mythos's vulnerability-finding effectiveness; token spending correlates directly with exploit quality, creating a "proof of work" dynamic for security.

*Why it matters: This is the first credible public evidence of a frontier model crossing a threshold where its offensive cyber capabilities require controlled distribution rather than standard API access. The NSA deployment despite blacklisting signals that government demand will outpace any voluntary restriction regime — the policy gap between capability and governance is now measurable in specific CVEs.*

**Cloudflare Agents Week: A Full Infrastructure Stack for Autonomous Agents**

- Cloudflare shipped Agent Memory (persistent memory outside context windows), Artifacts (Git-compatible versioned storage for agents), Browser Run (renamed browser automation with Live View and Human-in-the-Loop), a unified AI inference layer across 14+ model providers, Email Service for agents (public beta), and Project Think (next-gen Agents SDK with durable execution and sub-agents).
- Flagship (feature flags for agent deployments), Sandbox auth with zero-trust credential injection, and an enterprise MCP deployment that cuts token costs 94–99.9% via "Code Mode" round out the release.
- Agentic crawlers now represent ~10% of Cloudflare's total traffic, up 60% year-over-year.

*Why it matters: Cloudflare is making a credible bid to be the default infrastructure layer for agent deployment — not just CDN or edge compute. The combination of memory, versioned storage, browser automation, email, and sandboxed execution in one billing relationship is a direct challenge to assembling the same stack from AWS primitives. The MCP cost reduction numbers (94–99.9%) are the most concrete enterprise deployment data published by any major platform this week.*

**AWS Interconnect GA and MCP Deepening Signal AWS's Agentic Infrastructure Direction**

- AWS Interconnect is now generally available as a managed private connectivity service for multi-cloud environments, with a new last-mile option for branch offices and data centers — directly competing with Azure ExpressRoute and Google Cloud Interconnect on managed simplicity.
- AWS engineer Clare Liguori is actively shaping the MCP specification, and AWS is building managed MCP servers and testing draft concepts in production, signaling MCP as a first-class AWS primitive rather than a third-party integration.

*Why it matters: AWS is moving on two fronts simultaneously: hardening the physical network layer for multi-cloud enterprise workloads (Interconnect) while standardizing the agent protocol layer (MCP). The IAM-level cost allocation for Bedrock is a quiet but important enterprise feature — without it, agentic workloads become a budget black hole that kills adoption.*

**AI Agent Security: MCP Injection, IAM Misconfiguration, and the Vercel Breach**

- Vercel confirmed a security incident traced to a compromised third-party AI tool's Google Workspace OAuth app — a direct example of the supply-chain risk introduced by AI tooling with broad OAuth scopes.
- LogJack research demonstrated that LLM debugging agents consuming cloud logs are vulnerable to indirect prompt injection through log content; AWS, GCP, and Azure guardrails largely failed to detect log-embedded injections, with Azure Prompt Shield catching only 1 of 32 payloads.
- HashiCorp and AWS both published guidance this week on agentic AI access patterns: agent-assumed IAM roles and cached credentials persist beyond task completion, and misconfigured permissions scale impact at machine speed.
- Vault Enterprise 2.0 GA introduces workload identity federation for secret sync, eliminating long-lived static credentials for AWS Secrets Manager, Azure Key Vault, and Google Secret Manager.

*Why it matters: The Vercel breach is the first high-profile incident directly attributable to AI tool OAuth sprawl — expect this to become a standard attack vector as AI tools proliferate in developer environments. The LogJack findings are particularly concerning for platform engineers: cloud logs are a trusted data source that most security models don't treat as adversarial input.*

Sources: [1](https://www.bleepingcomputer.com/news/security/vercel-confirms-breach-as-hackers-claim-to-be-selling-stolen-data/) [2](https://arxiv.org/abs/2604.15368) [3](https://aws.amazon.com/blogs/security/secure-ai-agent-access-patterns-to-aws-resources-using-model-context-protocol/) [4](https://www.hashicorp.com/blog/agentic-ai-changes-the-shape-of-trust) [5](https://www.hashicorp.com/blog/vault-enterprise-20-modernizes-identity-security-at-scale) [6](https://www.hashicorp.com/blog/advancing-secret-sync-with-workload-identity-federation)

## What To Watch

- **MCP as AWS primitive:** With Clare Liguori shaping the spec and AWS building managed MCP servers, watch for MCP to appear as a first-class service in an upcoming AWS announcement — likely at re:Inforce or a dedicated launch. The Cloudflare enterprise MCP deployment data (94–99.9% token cost reduction via Code Mode) will pressure AWS to match on cost efficiency, not just availability.
- **Agent harness pricing shakeout:** Anthropic ($0.08/session-hour) vs. OpenAI (open-source harness) vs. Cloudflare (infrastructure-layer pricing) represents three incompatible business models for the same product category. Enterprise procurement decisions made in the next 90 days will establish lock-in that's hard to reverse once agent memory and persistent sessions accumulate.
- **OAuth/AI tool supply chain attacks:** The Vercel breach (compromised AI tool OAuth app) and LogJack findings (cloud log injection) together define a new attack surface that most security teams haven't modeled. Watch for CVEs and incident disclosures accelerating as threat actors operationalize these vectors — and for cloud providers to add AI-tool-specific OAuth scope restrictions.
