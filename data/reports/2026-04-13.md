**Cloudflare Agents Week: Infrastructure Bets on the Agentic Era**

- Sandboxes provide secure, burstable execution environments for agents with fast state restoration; Dynamic Workers isolates are 100x faster and use 1/10 the memory of containers.

*Why it matters: Cloudflare is making a coherent architectural bet that the edge/serverless layer — not Kubernetes clusters — is the right substrate for agent execution. The combination of fast isolates, durable state, and identity-aware egress proxies addresses the four hardest production agent problems simultaneously. If this bet lands, it reshapes where agent workloads run.*

**Ingress-NGINX Is Dead: Migrate Now**

- Ingress-NGINX officially reached end-of-life in March after being maintained by one or two volunteers; critical vulnerabilities CVE-2026-24512 and CVE-2026-3288 now have no supported fixes, and the earlier IngressNightmare (CVE-2025-1974, CVSS 9.8) allowed remote code execution and cluster secret exposure.
- The controller was used by roughly half of all cloud-native environments; migration targets include Envoy Gateway, NGINX Gateway Fabric, and Traefik via the Kubernetes Gateway API.
- Kubernetes 1.36 (launching April 22) adds 20 new alpha features targeting AI/ML workloads, including workload-aware preemption and HPA scale-to-zero on external metrics.

*Why it matters: This is not a routine deprecation — it's a security emergency affecting roughly half the Kubernetes ecosystem with no patch path. Teams that haven't started migration are running unpatched critical vulnerabilities in production today. The Gateway API migration is non-trivial and requires controller selection, parallel deployment, and DNS cutover planning; start immediately.*

Sources: [1](https://www.datadoghq.com/blog/migrate-to-gateway-api/) [2](https://aws.plainenglish.io/the-death-of-ingress-nginx-a-post-mortem-nobody-wanted-to-write-065a481160fd) [3](https://palark.com/blog/kubernetes-1-36-release-features/)
