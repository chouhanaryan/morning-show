**Ingress NGINX Reaches EOL with Unpatched Critical CVEs**
Ingress NGINX reached end-of-life in March with two critical vulnerabilities — CVE-2026-24512 and CVE-2026-3288 — that have no supported fixes, forcing organizations to migrate to the Kubernetes Gateway API. Detailed migration guidance covers controller selection, parallel deployment strategies, and DNS cutover procedures. This is a significant deprecation affecting a widely deployed Kubernetes ingress controller.

## What To Watch

- **Ingress NGINX migration deadline pressure:** With EOL confirmed and critical CVEs unpatched, organizations still running Ingress NGINX face active security exposure. The Gateway API migration path is now well-documented but operationally non-trivial at scale — watch for tooling and managed migration offerings to emerge.
- **Anthropic's IPO trajectory vs. compute constraints:** Anthropic's $30B run rate is impressive, but OpenAI's characterization of them as compute-constrained — with only 7–8 GW projected by end of 2027 vs. OpenAI's 30 GW target by 2030 — will be a central investor narrative. The Google/Broadcom TPU deal is the key counter-signal to watch.
- **Agent reliability frameworks becoming a procurement requirement:** The Agent Reliability Score framework (28 tests across data, architecture, infrastructure, and monitoring) and Anthropic's Managed Agents architecture both signal that "production-ready" agent infrastructure is becoming a defined, auditable standard — expect this to influence enterprise buying criteria within 6–12 months.
